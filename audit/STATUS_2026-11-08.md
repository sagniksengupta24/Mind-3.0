## 4. Gate soundness status

### 4.1 Gate 4 never requests a hold path — OPEN

`[VERIFIED]` The auto-generated STA script (`verifier.py:2988-3002`) contains
only:

```tcl
report_checks
report_wns
```

There is no `report_checks -path_delay min` (or equivalent) request. The hold
check at `verifier.py:3094` fires only when `hold_wns_ps is not None`, i.e.
only if a user-supplied custom `.tcl` happened to emit hold data. In the
default path hold WNS is `None`, so the hold branch is dead and a hold
violation cannot fail Gate 4.

### 4.2 CDC contract waiver — OPEN

`[VERIFIED]` `verifier.py:1676-1693` adds Gate 6 to `_OPTIONAL_GATE_NAMES`
when a contract declares `cdc_skip_reason == "contract_declares_no_cdc"` and
`require_cdc` is false. Optional gates do not count toward `is_skipped`, so a
contract can self-declare "no CDC" and Gate 6's absence does not invalidate
`silicon_verified`. This is a contract-side waiver of a signoff gate, not an
independent proof that no clock-domain crossings exist.

### 4.3 Gate 6 structural and crux backends are unsandboxed — OPEN

`[VERIFIED]` `_run_gate6_structural_cdc` (`verifier.py:3373`) invokes
`subprocess.run` at `verifier.py:3416` on
`python -m tools.cdc_checker ...` with `cwd=_repo_root()`. `_run_gate6_crux`
(`verifier.py:3516`) invokes `subprocess.run` at `verifier.py:3543` with
`cwd=ws`. Neither goes through the `BubblewrapSandbox` / `MacOSSandbox`
runner used by the other EDA gates, so a model-produced RTL file is fed to a
host process outside the sandbox while the gate reports a normal verdict.

### 4.4 Loopback-only check is a substring test — OPEN

`[VERIFIED]` `driver.py:853-858`:

```python
base_lower = self.base_url.lower()
if not ("127.0.0.1" in base_lower
        or "localhost" in base_lower
        or "::1" in base_lower):
```

This passes hostnames such as `http://localhost.example.com`,
`https://127.0.0.1.evil.tld`, or a userinfo trick. The air-gap guarantee needs
a parsed-host equality check, not substring containment.

### 4.5 Mock fallback can fabricate passing tool output — OPEN (latent)

`[VERIFIED]` `SiliconSignoffVerifier` accepts `allow_mock_fallback`
(`verifier.py:1403`, stored at `1449`). When enabled, missing-tool branches
return `passed: True` with `"[SIMULATED - NOT REAL TOOL OUTPUT]"`
stdout for compile (`1861-1868`), formal LEC (`2104-2162`), SymbiYosys
(`2475-2495`), and coverage (`2732-2751`). The flags are set `False` by the
production driver and benchmark runner (`driver.py:2158`,
`benchmarks/runner.py:502`, `benchmarks/baselines.py:194,468`), so today this
is latent rather than active. It is still a one-parameter path from
"tool absent" to "gate passed", and the contract does not forbid a caller from
enabling it.

### 4.6 Formal signoff is bounded BMC presented as proof — OPEN

`[VERIFIED]` `build_sby_config` (`contracts.py:1255`) emits `mode bmc`
(`contracts.py:1277`) at `depth 25` (`contracts.py:1278`; `verifier.py:2376`
passes `depth=25`). A bounded model check to depth 25 is evidence that no
counterexample exists within 25 cycles; it is not an unbounded proof. Gate 2
and the signoff summary nevertheless describe the design as formally verified
(`driver.py:1701` says "breached in SymbiYosys BMC"; the plan/README language
is stronger). No induction or unbounded engine is used.

## 8. Risks

1. **False confidence from a green suite.** 579 passing tests coexist with six
   soundness gaps because the tests encode current behavior.
2. **Signoff overstatement.** BMC depth 25 and a contract-declared CDC skip can
   both surface as "verified" in reports.
3. **Unsandboxed CDC execution** on model-authored RTL (`verifier.py:3416,3543`).
4. **Non-reproducible evidence.** Headline numbers cannot be regenerated from
   the committed tree.
5. **Documentation contradiction.** README, `agent_handoff.md`, and
   `linux_verification.md` describe different worlds; a reader cannot tell
   which number is current.

## 9. What would actually move the needle

Ordered by cost/benefit, and all outside the read-only scope of this audit:

1. Make Gate 4 request a min-path report and fail when hold data is absent.
2. Remove the contract-side Gate 6 waiver, or require an independent
   no-CDC proof to use it.
3. Route Gate 6 structural/crux through the same sandbox as other gates.
4. Replace the loopback substring check with `urllib.parse` host equality.
5. Delete `allow_mock_fallback` or make the benchmark runner reject any
   `simulated: True` transcript at the harness layer.
6. Rename Gate 2 output from "verified" to "BMC-bounded (depth 25)" in every
   report and README claim.
7. Commit a held-out manifest and at least one reproducible baseline so the
   headline is derivable from the repo.
